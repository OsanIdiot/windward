# 바람의 항로 / Windward v0.10

16세기 실제 항구를 찾아가는 모바일 웹 경제·모험 게임입니다. 전투 없이 교역, 납품 의뢰, 해도 조사와 발견으로 성장합니다. 첫 해역은 1550년경의 유럽·지중해이며 세계 전체 지도는 아닙니다.

## 실행

공개 플레이 주소: https://osanidiot.github.io/windward/

모바일 브라우저에서 위 주소로 접속하면 됩니다. 테스트 모드는 주소 뒤에 `?test=1`을 붙입니다. PC의 로컬 주소와 공개 주소, 각 기기의 저장 기록은 서로 별개입니다.

이 폴더에서 Node.js로 실행합니다.

```powershell
node server.cjs
```

http://127.0.0.1:4173/?v=23 에서 플레이합니다. 효과음 파일 로딩에는 HTTP 서버가 필요합니다. index.html을 직접 열면 파일 로딩이나 저장 기능이 브라우저 정책에 따라 제한됩니다.

같은 Wi-Fi의 휴대폰에서 접속하려면 서버를 중지한 뒤 아래 명령으로 시작하고, 휴대폰에서 PC의 LAN IP와 4173 포트로 접속합니다. 개인 네트워크 방화벽 허용이 필요할 수 있습니다.

```powershell
$env:HOST = '0.0.0.0'
node server.cjs
```

## 항해 조작

모바일 해도는 최소 300px 높이를 유지하며 제목과 확대·축소·내 배·전체 해역 버튼은 지도 위의 별도 영역에 표시합니다. 높이가 짧은 화면에서는 지도를 납작하게 압축하지 않고 필요한 만큼 세로 스크롤을 허용합니다. 귀환 지원은 버튼 이름과 비용을 두 줄로 나누되 `3일 / 최대 40 G`는 한 줄로 유지합니다.

해도의 `항해 목표` 버튼을 누르면 경제·모험 목표와 현재 진행 상황을 팝업으로 확인합니다. 닫기 또는 Escape로 돌아가며, 팝업을 읽는 동안 해도의 자동 복귀는 보류됩니다. 수동·자동 모드 선택 버튼 없이 바다를 누르면 수동항해, 방문한 항구를 누르면 자동항해합니다.

모든 선박의 실제 이동 최고속도를 기존보다 30% 낮췄습니다. 기본 속도는 초당 지도 45단위에서 31.5단위로 변경했으며 수동·자동항해에 공통 적용됩니다. 선박 등급별 속도 배율과 가속 시간, 이동 거리 기준 경비·게임 날짜 계산은 유지합니다. 같은 항로를 이동하는 실제 시간만 더 길어집니다.

- 접속하면 입장 화면이 먼저 열립니다. 처음에는 '항해 시작', 저장 기록이 있으면 '이어하기'를 누릅니다. 게임 안에서는 상단 제목·소개와 푸터가 표시되지 않습니다.
- 게임의 작은 '입장 화면' 버튼은 항해를 정지하고 진행을 저장한 뒤 입장 화면으로 돌아갑니다. 입장 화면 아래의 '새 항해 시작'은 확인 후 현재 모드의 기록만 초기화합니다.
- 리스본 항구 풍경에서 시작합니다. 그림 위 교역소·탐험·의뢰·선박·항해 일지 표지를 누르면 해당 기능 창이 열립니다. '항구 풍경' 또는 Escape로 닫습니다. '항구' 표지를 누르면 배를 가까이 보는 항해 화면으로 나갑니다. 화면 전환만으로 시간이나 경비가 들지는 않습니다.
- 직접 조타: 배 주변 바다를 클릭·터치하면 그 방향으로 계속 움직입니다. 다시 누르면 방향을 바꾸며 해안·해역 경계·예산 한계 앞에서 안전하게 정지합니다. 항해 화면에 초점을 두면 방향키로 조타하고 스페이스로 정지·계속합니다.
- 출발·계속 시 정지 상태에서 약 3초에 걸쳐 순항 속도로 가속합니다. 크게 방향을 바꾸거나 자동항해의 모퉁이에 접근하면 감속하고 직선에서 다시 가속합니다. 속도 표시는 해당 선박 최고 속도 대비 비율입니다. 안전한 기존 항로를 따라 이동하며 선체 방향은 서서히 회전합니다. 정지 버튼·도착·충돌 방지는 즉시 정지하고, 경비와 게임 날짜는 여전히 실제 이동 거리만으로 계산합니다.
- '해도 열기' 또는 미니맵으로 기존 항해도를 펼칩니다. '배로 돌아가기'로 복귀하며 두 화면은 같은 위치·항로·진행을 공유합니다. 가까운 항해 화면에는 파도, 항적, 돛배 회전, 실제 해안선, 나침반과 가까운 항구가 표시됩니다. 육지의 작은 숲은 장식이며 실제 식생 자료가 아닙니다. 날씨·바람의 물리 효과는 아직 없습니다.
- 해도에서 수동·자동항해를 시작하거나 '계속'을 누르면 즉시 가까운 항해 화면으로 전환합니다. 이동 중에 해도 버튼이나 미니맵을 누르면 약 3초 동안 해도를 보여준 뒤 자동 복귀합니다. 배의 이동과 소리는 그대로 이어집니다. 드래그·확대 조작 또는 도움말을 마치면 3초를 다시 셉니다. 정지·도착·백그라운드 전환·입장 화면 복귀 시에는 자동 전환을 취소하며, 정지 상태에서는 시간제한 없이 해도를 살펴볼 수 있습니다.
- 미방문 항구는 지도·목록·의뢰에 '미확인 항구'로 표시됩니다.
- 해도 수동항해: 바다를 클릭하거나 터치하면 현재 위치에서 그 지점까지만 직선으로 이동합니다. 육지 자체나 육지를 가로지르는 이동은 거부됩니다. 해안을 따라 중간 지점을 지정해 우회합니다.
- 항구의 해상 정박점 가까이에 접근하면 배가 멈추고 '입항' 버튼이 나타납니다. 직접 버튼을 눌러야 항구 화면으로 들어가며, 최초 입항 시 이름과 자동항해를 해제합니다. 접근만으로는 발견 처리하거나 교역 메뉴를 열지 않습니다.
- 자동·수동항해로 항구 앞에 도착해도 입항하지 않고 바다를 눌러 계속 출발할 수 있습니다. 이미 도착 범위 안에 있는 동안은 같은 항구의 도착 판정으로 반복 정지하지 않습니다. 밖으로 벗어났다가 다시 접근하거나 항구를 명시적으로 목표로 선택하면 정상적으로 도착·입항할 수 있습니다.
- 방문한 항구를 지도나 목록에서 클릭하면 육지를 피하는 경로를 따라 자동항해합니다. 미방문 항구에는 자동항해할 수 없습니다. 목록의 미확인 항구 버튼은 위치만 보여줍니다.
- 정지/계속으로 항해를 제어하고 새 바다 지점을 눌러 수동 항로로 바꿀 수 있습니다. 이동 중 상태와 위치가 저장됩니다.
- 지도는 드래그로 이동, 버튼/휠/두 손가락으로 확대·축소합니다. '내 배'는 현재 위치로, '전체 해역'은 유럽·지중해 전체로 돌아갑니다.
- 해상/항구 상태와 입항 대기 상태도 저장됩니다. 해상에서 재접속하면 가까운 항해 화면으로 복원되고 이동은 정지 상태입니다. 탭이 배경으로 가도 항해를 일시 정지합니다.
- 경비는 실제 이동 거리에 따라 게임 속 날짜가 진행될 때 차감됩니다. 여러 번 나누어 클릭해도 거리 누적값은 유지됩니다. 해류 지도를 얻으면 하루 경비가 8 G에서 7 G로 줄어듭니다.
- 경비가 부족하거나 길을 잃으면 해상 화면에서 마지막 방문 항구 앞바다로 귀환 지원을 받을 수 있습니다. 3일이 지나고 최대 40 G를 지불합니다. 금화가 없어도 이용 가능하며 귀환 후 '입항'을 눌러 항구로 들어갑니다.

## 항해 소리

효과음은 `assets/audio/`의 WAV 9개로 분리되어 있습니다. `audio-config.js`에서 파일 경로·개별 음량·캐시 버전을 관리합니다. 같은 이름의 WAV를 교체하거나 설정에서 다른 파일을 지정하면 됩니다. 자세한 역할과 교체 절차는 [효과음 교체 안내](assets/audio/README.md)를 참고하세요. 게임 실행 중에는 합성하지 않고 파일을 불러와 재생합니다.

선회 중에는 목재·밧줄이 힘을 받는 듯한 '끼익끼익' 합성음이 추가됩니다. 수동 조타와 자동항해 모두 엔진의 실제 선회 상태에 반응하며 속도가 높을수록 조금 더 크게 들립니다. 긴 선회에서는 1.7~2.3초 간격으로 제한하여 소리가 겹치지 않게 합니다. 직선으로 돌아오면 짧게 페이드아웃하고 정지·입항·음소거·화면 이탈 시에는 중단합니다. 참고 영상의 녹음은 사용하지 않습니다.

시작·이어하기를 누른 뒤 바다에 나가면 선체 옆으로 흐르는 물살과 돛을 스치는 바람 소리가 재생됩니다. 해변처럼 크게 밀려왔다 빠지는 파도 대신, 이동할 때 이어지는 잔물살에 드문 목재 삐걱임과 짧은 돛 천의 펄럭임을 작게 섞습니다. 정지하면 물살을 크게 낮추고 선박 소리는 끕니다. 항해 화면과 해도는 같은 소리를 공유하며, 직접 입항하면 짧은 종소리가 나고 바다 소리는 잦아듭니다. 배경음악은 없고 실제 선박 녹음이 아닌 합성 효과음입니다.

기본 입항 종 파일은 '땡땡땡~~~' 세 번 빠르게 울립니다. 타격 간격은 균일하게 0.18초이며 앞의 두 소리는 0.5초 이내로 짧게 잦아들고 마지막에만 약 3.7초의 잔향을 남깁니다. 높은 금속성 울림을 8개 비정수 배음으로 미리 합성해 저장한 WAV입니다. 참고 파일 및 그 편집본은 게임에 포함하지 않습니다. 빠르게 다시 입항하거나 출항하면 이전 종소리는 끊어 중첩을 막습니다.

물살 파일에는 기본 게인 .2와 필터를 미리 적용했고, 물살·바람·선박 소리는 현재 속도에 맞춰 부드럽게 변합니다. 바다에서는 멀리 들리는 갈매기 파일을 간헐적으로 재생합니다. 파일 로딩 후 첫 울음은 약 10~16초 뒤, 이후 약 22~40초 간격이며 항구 안·음소거·백그라운드에서는 울지 않습니다.

입장 화면과 게임 상단의 '소리 켜짐/꺼짐' 버튼으로 전체 음소거를 바꿉니다. 설정은 게임 기록과 별도로 이 브라우저에 저장됩니다. 입장 화면으로 돌아가거나 탭을 숨기면 오디오 처리를 멈춥니다. 모바일 브라우저에서 '소리 대기'가 보이면 화면을 한 번 터치하세요. Web Audio 미지원 환경에서는 소리 없이 게임을 계속할 수 있습니다.

현재 WAV는 `build-audio.cjs`로 미리 생성한 합성 효과음이며 실제 녹음은 아닙니다. 외부 음원·유료 라이브러리는 포함하지 않았습니다. Web Audio는 파일 디코딩·믹싱·재생만 담당합니다. 시작·이어하기 후 파일을 한 번 불러오며 로딩 실패한 효과음은 생략하고 게임은 계속됩니다. 기본 음량은 낮게 설정되어 있고 기기의 미디어 음량으로 조절합니다.

## 경제와 모험

항구별 고정 시세로 교역하고 선박을 교체합니다. 경제 목표는 항구 8곳 방문, 선박 1회 업그레이드, 금화 5,000 G입니다. 리스본에서 밀을 10자루 구매한 뒤 남쪽 곶을 돌아 동쪽 항구를 찾아 판매해 보세요.

탐험 5곳의 단서를 모아 마지막 서고를 조사합니다. 의뢰 5건은 출발 항구에서 수락하고 직접 물품을 준비해 도착 항구의 의뢰 탭에서 납품합니다. 일반 판매로는 의뢰가 완료되지 않습니다. 시간제한은 없으며 보상은 1회만 받습니다. 모험 목표는 발견 5곳과 의뢰 3건입니다. 추가된 바르셀로나·마르세유·라구사는 현재 교역 거점이며 개별 탐험·의뢰는 없습니다.

## 선박과 테스트 모드

선박 메뉴에서 순서대로 교체합니다. 기존 세 단계와 저장 기록은 그대로 유지됩니다. 가격은 단계별 교체 비용이며 선박 명칭·제원·등급은 게임용 설정입니다.

| 단계 | 선박 | 적재량 | 속도 | 교체 비용 |
| --- | --- | --- | --- | --- |
| 1 | 작은 돛배 | 24칸 | 1배 | 시작 배 |
| 2 | 무역용 캐러벨 | 40칸 | 1.3배 | 650 G |
| 3 | 상인용 카락 | 64칸 | 1.65배 | 1,600 G |
| 4 | 대형 카락 | 100칸 | 2배 | 3,200 G |
| 5 | 원양 무역선 | 150칸 | 2.5배 | 6,000 G |
| 6 | 대형 상선 | 220칸 | 3.1배 | 11,000 G |
| 7 | 대양 기함 | 320칸 | 4배 | 20,000 G |

선박 메뉴의 '테스트 모드 열기' 또는 http://127.0.0.1:4173/?v=5&test=1 로 들어갑니다. 첫 실행 시 일반 진행을 복사하고 이후에는 별도 localStorage 키에 저장합니다. 상단 배너로 테스트 모드임을 표시합니다. 선박 메뉴에서 '금화 +50,000 G'와 '최고 등급 배 장착'을 이용할 수 있습니다. 테스트 초기화도 일반 기록에는 영향을 주지 않습니다. 일반 플레이로 돌아가면 기존 일반 기록을 이어갑니다. 해상에서 시작했다면 먼저 입항하세요.

## 지도와 역사적 범위

항구 배경은 모든 항구에서 공통으로 사용하는 창작 지중해 풍경이며 특정 도시의 실제 모습을 복원한 그림은 아닙니다. 내장 이미지 생성 도구로 제작한 배경과 생성 프롬프트는 [배경 제작 기록](assets/README.md)에 설명되어 있습니다. 모바일용 WebP 파일은 약 421 KiB이며 시설 버튼과 글자는 이미지가 아닌 HTML로 구현되어 있습니다.

실제 항구: 리스본, 카디스, 제노바, 알렉산드리아, 베네치아, 바르셀로나, 마르세유, 라구사(현재 두브로브니크). 이름과 소속은 1550년경을 배경으로 합니다. 당시 국경선이나 정확한 도시 지형을 복원한 지도는 아닙니다.

해안선은 Natural Earth 1:50m 현대 육지 폴리곤을 메르카토르 좌표로 투영한 것입니다. 당시 매립지·하천·석호의 변화는 복원하지 않았으며, 작은 만과 섬은 데이터 해상도에 따라 생략될 수 있습니다. 화면의 육지 폴리곤과 충돌 판정은 동일한 데이터를 사용합니다. 실제 도시 위치와 입항용 외해 정박점은 구분되며, 강·석호 안쪽의 세밀한 입항은 생략했습니다. 교역 가격, 의뢰, 발견 이야기, 항해 속도와 비용은 역사적 실측이 아닌 게임 규칙입니다.

지형 데이터를 수정·재생성하려면 원본 파일을 유지한 상태에서 다음을 실행합니다.

```powershell
node build-geography.cjs
```

## 저장 호환성

속도와 방향 정보가 없는 기존 저장도 그대로 읽습니다. 위치·금화·화물·항로는 유지하며 재접속 시 속도는 0에서 다시 출발합니다.

v0.1/v0.2/v0.3의 금화·선박·화물·의뢰·탐험을 유지합니다. v0.3 저장은 정박 상태면 항구 화면으로, 해상이면 항해도로 이어집니다. 기존 가상 항구의 방문 기록은 루메→리스본, 세드라→카디스, 아주르→제노바, 사프라→알렉산드리아, 벨항→베네치아로 대응시킵니다. 새 게임은 리스본만 공개되어 있습니다. 기존에 달성한 경제 목표는 유지됩니다.

브라우저 localStorage에 저장하므로 사이트 데이터 삭제, 다른 기기·주소·브라우저에서는 이어지지 않습니다. 한 탭에서 플레이하세요. 멀티플레이·클라우드 저장·결제·광고는 포함하지 않습니다.

## 검증

`node goals-browser-test.cjs`는 목표 팝업의 진행 상황, 모바일 크기·스크롤, 닫기·Escape·초점 복귀, 자동 복귀 보류와 모드 버튼 없는 수동·자동항해 전환을 검사합니다.

`node mobile-layout-browser-test.cjs`는 작은 휴대폰부터 태블릿까지 항구·항해·해도의 높이, 버튼 겹침, 시설 창·설명 스크롤, 4열 2행 항구 목록과 화면 크기 변경을 검사합니다. 항구 8곳은 가로 스크롤 없이 모두 표시합니다. 해도의 펼침 설명은 제거하고 항구 목록 바로 아래에 현재 항로·도착 안내를 항상 표시합니다. 작은 화면에서는 내용을 자르지 않고 필요한 만큼 세로로 스크롤할 수 있습니다.

`node port-departure-browser-test.cjs`는 자동항해 도착 후 입항 없이 바다 클릭·모바일 터치로 출발, 방문 기록 보존, 재접속·계속 및 다시 도착하여 입항하는 흐름을 검사합니다. 엔진 테스트는 모든 자동항해 목적지에서 일반·최고 등급 선박의 재출발과 미확인 항구 우회도 포함합니다.

`node audio-loading-browser-test.cjs`는 느린 파일 로딩 도중 음소거·출항·화면 이탈, 늦어진 입항음 취소와 파일 누락·손상 시 게임 계속을 검사합니다. `audio-assets.test.cjs`는 배포 파일 존재 여부와 오프라인 생성기의 파형을 검사합니다. 기본 음원의 길이에 의존하는 브라우저 테스트는 다른 길이의 녹음으로 교체할 때 기대값도 조정해야 합니다.

`node turn-audio-browser-test.cjs`는 실제 조타 시 선회음, 직선 항해에서의 미재생, 해도 전환, 중복 방지, 음소거·정지·입항 시 중단을 검사합니다.

`node motion-browser-test.cjs`는 실제 화면의 출발 가속·선회 감속·직선 재가속, 속도 표시, 정지·재접속·해도 전환 시 상태 보존, 모바일 터치를 검사합니다. 엔진 테스트에는 프레임 간격별 일관성, 모퉁이 사전 감속, 경비 계산과 이전 저장 호환성도 포함됩니다.

`node chart-peek-browser-test.cjs`는 출항·계속 시 자동 전환, 해도/미니맵 3초 확인, 위치 이동 유지, 정지·도착·메뉴 복귀 시 취소, 재열기, 드래그 도중 전환 방지와 모바일 터치를 검사합니다.

`node audio-browser-test.cjs`는 실제 Web Audio 신호, 사용자 조작 후 활성화, 이동/정지 믹스, 음소거 저장, 입항 종소리, 백그라운드/입장 화면 정지, 모바일 터치 에뮬레이션과 미지원 환경을 검사합니다. 실제 iOS 기기에서의 청감·자동재생 정책 검증은 별도로 필요합니다.

`node voyage-browser-test.cjs`는 클릭·터치·키보드 조타, 해도 전환 시 위치 보존, 정지·저장 복원, 미확인 항구의 명시적 입항, 자동항해와 모바일 레이아웃을 검사합니다. `BASE_URL`로 공개 사이트도 검사할 수 있습니다.

`node harbor-browser-test.cjs`는 항구 배경 로딩, 시설 창 5개, 키보드 초점 복귀, 모바일 버튼 겹침, 교역, 항해도 전환을 검사합니다. `BASE_URL` 환경 변수로 공개 사이트를 지정할 수 있습니다.

`main`에 변경을 올리면 GitHub Actions가 단위 테스트를 실행하고, 성공한 경우 게임 실행 파일만 GitHub Pages로 배포합니다. 저장소 설정의 Pages는 GitHub Actions를 게시 소스로 사용합니다. 미리보기 이미지, 로컬 의존성, 환경 파일은 커밋에서 제외합니다.

```powershell
node --test engine.test.cjs navigation.test.cjs
```

단위 테스트는 입항 전 기능 차단, 명시적 입항, 무료 화면 전환, 7단계 선박 구매·화물·항해·저장 호환성 등을 포함합니다. Playwright와 Microsoft Edge가 있는 환경에서는 node browser-test.cjs로 클릭·터치·입항·항구 메뉴·자동항해·저장 호환성과 모바일 레이아웃을 확인할 수 있습니다. node ship-browser-test.cjs는 선박 구매와 테스트 도구, 일반/테스트 저장 분리를 검증합니다. node entry-browser-test.cjs는 입장 화면, 시작·이어하기, 복귀 시 정지, 초기화 확인, 모바일 레이아웃을 검증하며 BASE_URL 환경 변수로 배포 주소도 검사할 수 있습니다. Playwright는 개발 검증용이며 게임 실행에는 필요하지 않습니다.

## 라이선스와 출처

게임 코드와 직접 제작한 SVG, 현재 포함된 합성 WAV 효과음은 MIT 라이선스입니다. 지리 데이터는 Natural Earth의 퍼블릭 도메인 데이터로 MIT 코드와 별도입니다. 실행 시 외부 API·지도 서비스·유료 소재·웹폰트를 사용하지 않습니다. 나중에 외부 녹음으로 교체할 경우 해당 음원의 이용 조건은 별도로 확인해야 합니다.

- [Natural Earth 이용 조건](https://www.naturalearthdata.com/about/terms-of-use/): 지리 데이터는 퍼블릭 도메인입니다.
- [Natural Earth 원본 육지 데이터](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson): 원본은 natural-earth-land.geojson, 생성 결과는 geography.js입니다.
- [UNESCO: 리스본의 벨렝 탑과 수도원](https://whc.unesco.org/en/list/263/): 대항해 시대의 리스본과 항구 관련 유산.
- [카디스 시청: 도시 역사](https://turismo.cadiz.es/es/node/17545): 16세기 대서양 교역항의 역할.
- [UNESCO: 제노바](https://whc.unesco.org/en/list/1211/): 16세기 후반 해상·금융 도시.
- [UNESCO: 베네치아](https://whc.unesco.org/en/list/394/): 석호와 해상 교역 도시.
- [UNESCO: 두브로브니크](https://whc.unesco.org/en/list/95/): 라구사의 해상 교역 역사.
