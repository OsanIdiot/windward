## 0.1.2 해상 발견

항해 화면의 **망원경**으로 주변 75 해도 단위 안에서 육지에 가리지 않은 단서를
찾습니다. 수평선의 작은 그림과 '단서 있음' 표시를 참고하세요. 찾은 단서는 해도에
남으며, 도감의 **단서로 접근**은 기존 수동항해를 사용합니다. 육지에 막히면 해도에서
우회해야 합니다. 목표 7 해도 단위 안에서 완전히 정지하면 **조사하기**가 열립니다.
정지 버튼은 기존과 같이 자연스럽게 감속하며, 도감을 보는 동안에도 항해는 계속됩니다.

물새·난파 흔적·암초·돌고래·표류 도기의 다섯 창작 이야기가 있습니다. 각 발견은
최초 1회만 80~130 G와 명성을 주며 이름과 이야기를 기록합니다. 항구의 탐험 메뉴와
해도의 항해 목표에서도 해상 발견 도감을 다시 열 수 있습니다. 기존 항구 탐험
다섯 개와 별도이며, 미확인 항구의 이름이나 자동항해 권한은 열지 않습니다.

저장 형식은 version 4를 유지하며 예전 기록에는 빈 `seaClues`, `seaDiscoveries`를
추가합니다. 일반·테스트 모드는 기존처럼 분리됩니다. `node --test sea-discoveries.test.cjs`와
`node discovery-browser-test.cjs`가 마이그레이션·거리·정지·중복 보상·화면·재접속을 검사합니다.
브라우저 테스트는 Playwright/Edge가 필요하며 `BASE_URL`로 테스트 서버를 지정할 수 있습니다.

16세기 실제 항구를 찾아가는 모바일 웹 경제·모험 게임입니다. 전투 없이 교역, 납품 의뢰, 해도 조사와 발견으로 성장합니다. 첫 해역은 1550년경의 유럽·지중해이며 세계 전체 지도는 아닙니다.

## 실행

공개 플레이 주소: https://osanidiot.github.io/windward/

모바일 브라우저에서 위 주소로 접속하면 됩니다. 테스트 모드는 주소 뒤에 `?test=1`을 붙입니다. PC의 로컬 주소와 공개 주소, 각 기기의 저장 기록은 서로 별개입니다.

이 폴더에서 Node.js로 실행합니다.

```powershell
node server.cjs
```

http://127.0.0.1:4173/?v=23 에서 플레이합니다. 효과음 파일 로딩에는 HTTP 서버가 필요합니다. index.html을 직접 열면 파일 로딩이나 저장 기능이 브라우저 정책에 따라 제한됩니다.

모바일 플레이는 위 HTTPS 공개 주소를 이용하세요. 아래 설정은 LAN 개발 서버를 열지만, 일반 HTTP LAN 주소에서는 저장 권한에 필요한 Web Locks를 사용할 수 없어 플레이가 시작되지 않습니다. LAN에서 검사하려면 별도의 신뢰할 수 있는 HTTPS 설정이 필요합니다.

```powershell
$env:HOST = '0.0.0.0'
node server.cjs
```

## 화면 전환

v35에서는 모바일 오디오 권한이 끊기지 않도록 전체 문서 재로딩 대신 화면 상태를 새로 초기화합니다. 입항·출항 시 시설 콘텐츠를 다시 만들고, 창·입력 수량·지도 시점·스크롤 등 임시 상태를 초기화합니다. 금화·화물·항해·의뢰·발견 기록은 먼저 저장하며 그대로 유지됩니다. 입항 처리와 보상은 다시 실행하지 않습니다. 해도와 항해 화면 사이의 전환은 진행 중인 항해를 유지합니다.

항구는 `?screen=port`, 해상은 `?screen=sea`로 주소만 갱신하며 테스트 모드 등의 설정은 유지합니다. 주소를 직접 열거나 브라우저를 새로고침한 경우에는 입장 화면의 시작·이어하기를 누릅니다. 이전 버전의 일회용 페이지 인계 정보는 폐기합니다. 다른 탭에서 이어가기를 하면 기존 탭은 저장 권한을 넘기고 멈춥니다.

시작·이어하기를 누르는 동작에서 오디오를 활성화하고, 이후 입항·출항에서도 같은 오디오 컨텍스트를 유지합니다. 정상적인 화면 전환마다 소리 재개를 누를 필요가 없으며 입항 직후에는 종소리를 1회 재생합니다. 늦게 음원을 불러오거나 음소거를 해제한 뒤에는 지난 입항 소리를 뒤늦게 재생하지 않습니다. 기기의 앱 전환·절전 등 외부 사유로 재생이 중단되었을 때를 위한 소리 재개 기능은 유지합니다.

v34에서는 자동재생 요청이 대기 상태로 남더라도 이후 터치·클릭·키보드 입력에서 재생을 다시 요청합니다. 모바일 터치는 손을 떼는 이벤트에서도 처리합니다. 재생이 차단된 동안 소리 버튼은 '소리 재개'로 표시하며, 누르면 음소거로 바꾸지 않고 재개합니다. 이미 소리가 재생 중이면 기존처럼 음소거 버튼으로 동작합니다. 직접 끈 소리는 일반 화면 터치로 켜지지 않습니다.

## 항해 조작

v32에서 '선수 고정'을 항해 화면의 기본 시점으로 확정했습니다. 화면 위는 실제 북쪽이 아니라 뱃머리 방향이며, 배의 선회에 맞춰 해안선·항구 위치·항적이 반대로 회전합니다. 오른쪽 나침반 아래의 '시점' 버튼으로 기존 '북쪽 고정' 방식으로 전환할 수 있고 선택은 이 브라우저에 저장합니다. 시점 변경은 위치·속도·항로·금화에 영향을 주지 않습니다. 나침반 바늘과 N 표시는 실제 북쪽, 아래 방위 숫자는 배의 선수 방향입니다. 미니맵과 별도의 해도는 항상 북쪽이 위입니다. 클릭·터치·방향키는 현재 화면 방향을 실제 해상 방향으로 변환합니다.

모바일 해도는 기존 화면 높이 계산을 유지하며 확대·축소·내 배·전체 해역 버튼을 지도 안쪽 오른쪽 위에 고정합니다. 제목과 버튼이 겹치지 않도록 좁은 화면에서는 제목만 줄바꿈합니다. 귀환 지원은 버튼 이름과 비용을 두 줄로 나누되 `3일 / 최대 40 G`는 한 줄로 유지합니다.

해도의 `항해 목표` 버튼을 누르면 경제·모험 목표와 현재 진행 상황을 팝업으로 확인합니다. 닫기 또는 Escape로 돌아가며, 팝업을 읽는 동안 해도의 자동 복귀는 보류됩니다. 수동·자동 모드 선택 버튼 없이 바다를 누르면 수동항해, 방문한 항구를 누르면 자동항해합니다.

모든 선박의 실제 이동 최고속도를 직전 값의 절반으로 낮췄습니다. 기본 속도는 초당 지도 31.5단위에서 15.75단위로 변경했으며 수동·자동항해에 공통 적용됩니다. 최고 등급 배도 초당 126단위에서 63단위로 줄었습니다. 선박 등급별 속도 배율과 가속 시간, 이동 거리 기준 경비·게임 날짜 계산은 유지합니다. 같은 항로를 이동하는 실제 시간만 더 길어집니다.

- 접속하면 입장 화면이 먼저 열립니다. 처음에는 '항해 시작', 저장 기록이 있으면 '이어하기'를 누릅니다. 게임 안에서는 상단 제목·소개와 푸터가 표시되지 않습니다.
- 게임의 작은 '입장 화면' 버튼은 항해를 정지하고 진행을 저장한 뒤 입장 화면으로 돌아갑니다. 입장 화면 아래의 '새 항해 시작'은 확인 후 현재 모드의 기록만 초기화합니다.
- 리스본 항구 풍경에서 시작합니다. 그림 위 교역소·탐험·의뢰·선박·항해 일지 표지를 누르면 해당 기능 창이 열립니다. '항구 풍경' 또는 Escape로 닫습니다. '항구' 표지를 누르면 배를 가까이 보는 항해 화면으로 나갑니다. 화면 전환만으로 시간이나 경비가 들지는 않습니다.
- 직접 조타: 배 주변 바다를 클릭·터치하면 그 방향으로 계속 움직입니다. 다시 누르면 방향을 바꾸며 해안·해역 경계·예산 한계 앞에서 안전하게 정지합니다. 항해 화면에 초점을 두면 방향키로 조타하고 스페이스로 정지·계속합니다.
- 출발·계속 시 정지 상태에서 약 3초에 걸쳐 순항 속도로 가속합니다. 크게 방향을 바꾸거나 자동항해의 모퉁이에 접근하면 감속하고 직선에서 다시 가속합니다. 속도 표시는 해당 선박 최고 속도 대비 비율입니다. 안전한 기존 항로를 따라 이동하며 선체 방향은 서서히 회전합니다. 경비와 게임 날짜는 실제 이동 거리만으로 계산합니다.
- 정지 버튼·스페이스는 돛을 내리고 최고속도 기준 약 2.2초 동안 앞으로 흐르며 감속합니다. 감속 중에도 '계속' 또는 새 조타로 남은 속도를 이어받아 재출발합니다. 항구·지정한 바다 지점에는 남은 항로 거리에 맞춰 미리 감속하고, 완전히 정지한 뒤에만 입항합니다. 해도·항해 화면은 '감속 중'을 표시하고 물살·항적은 속도와 함께 줄어듭니다. 육지 충돌·조타의 해안/경계 끝·경비 부족은 즉시 안전 정지하며, 화면 이탈·입장 화면 복귀·탭 권한 인계·재접속도 이동을 즉시 중단합니다.
- '해도 열기' 또는 미니맵으로 기존 항해도를 펼칩니다. '배로 돌아가기'로 복귀하며 두 화면은 같은 위치·항로·진행을 공유합니다. 가까운 항해 화면에는 파도, 항적, 돛배 회전, 실제 해안선, 나침반과 가까운 항구가 표시됩니다. 육지의 작은 숲은 장식이며 실제 식생 자료가 아닙니다. 날씨·바람의 물리 효과는 아직 없습니다.
- 해도에서 수동·자동항해를 시작하거나 '계속'을 누르면 즉시 가까운 항해 화면으로 전환합니다. 이동 중에 해도 버튼이나 미니맵을 누르면 약 3초 동안 해도를 보여준 뒤 자동 복귀합니다. 배의 이동과 소리는 그대로 이어집니다. 드래그·확대 조작 또는 도움말을 마치면 3초를 다시 셉니다. 정지·도착·백그라운드 전환·입장 화면 복귀 시에는 자동 전환을 취소하며, 정지 상태에서는 시간제한 없이 해도를 살펴볼 수 있습니다.
- 미방문 항구는 지도·목록·의뢰에 '미확인 항구'로 표시됩니다.
- 해도 수동항해: 바다를 클릭하거나 터치하면 현재 위치에서 그 지점까지만 직선으로 이동합니다. 육지 자체나 육지를 가로지르는 이동은 거부됩니다. 해안을 따라 중간 지점을 지정해 우회합니다.
- 항구의 해상 정박점 가까이에 접근하면 배가 멈추고 '입항' 버튼이 나타납니다. 직접 버튼을 눌러야 항구 화면으로 들어가며, 최초 입항 시 이름과 자동항해를 해제합니다. 접근만으로는 발견 처리하거나 교역 메뉴를 열지 않습니다.
- 자동·수동항해로 항구 앞에 도착해도 입항하지 않고 바다를 눌러 계속 출발할 수 있습니다. 이미 도착 범위 안에 있는 동안은 같은 항구의 도착 판정으로 반복 정지하지 않습니다. 밖으로 벗어났다가 다시 접근하거나 항구를 명시적으로 목표로 선택하면 정상적으로 도착·입항할 수 있습니다.
- 방문한 항구를 지도나 목록에서 클릭하면 육지를 피하는 경로를 따라 자동항해합니다. 미방문 항구에는 자동항해할 수 없습니다. 목록의 미확인 항구 버튼은 위치만 보여줍니다.
- 정지/계속으로 항해를 제어하고 새 바다 지점을 눌러 수동 항로로 바꿀 수 있습니다. 이동 중 상태와 위치가 저장됩니다.
- 지도는 드래그로 이동, 버튼/휠/두 손가락으로 확대·축소합니다. '내 배'는 현재 위치로, '전체 해역'은 유럽·지중해 전체로 돌아갑니다.
- 해상/항구 상태와 입항 대기 상태도 저장됩니다. 해상에서 재접속하면 가까운 항해 화면으로 복원되고 이동은 정지 상태입니다. 탭이 배경으로 가도 항해를 일시 정지합니다.
- 경비는 실제 이동 거리에 따라 게임 속 날짜가 진행될 때 차감됩니다. 여러 번 나누어 클릭해도 거리 누적값은 유지됩니다. 해류 지도를 얻으면 하루 경비가 8 G에서 7 G로 줄어듭니다.
- 경비가 부족하거나 길을 잃으면 해상 화면에서 마지막 방문 항구 앞바다로 귀환 지원을 받을 수 있습니다. 3일이 지나고 최대 40 G를 지불합니다. 금화가 없어도 이용 가능하며 귀환 후 '입항'을 눌러 항구로 들어갑니다.

## 항해 소리

효과음은 `assets/audio/`의 WAV 9개로 분리되어 있습니다. v37에서는 `audio-config.js`의 `sfx.sounds`에 현재 9개를 모두 효과음(SFX)으로 분류했습니다. 물살·바람처럼 계속 반복되는 소리도 음악이 아닌 환경 효과음입니다. `sfx.gain`은 효과음 공통 음량, 각 파일의 `gain`은 개별 음량, `master`는 전체 음량입니다. 지금까지의 음량은 유지했습니다. 음악(BGM)은 `music.tracks`라는 별도 빈 목록과 `music.gain`을 준비했으며 아직 음악 파일이나 음악 재생 기능은 추가하지 않았습니다. 기존 소리 버튼과 저장된 음소거 설정은 현재 효과음에 적용됩니다.

같은 이름의 WAV를 교체하거나 설정에서 다른 파일을 지정하면 됩니다. 자세한 역할과 교체 절차는 [효과음 교체 안내](assets/audio/README.md)를 참고하세요. 게임 실행 중에는 합성하지 않고 파일을 불러와 재생합니다.

v36에서는 선체 삐걱임과 선회음에 사용자가 제공한 Pixabay 음원 4개를 편집해 적용했습니다. 선체음은 18초 안에 세 구간과 여백을 배치한 루프, 선회음은 2.9·2.8·2.3초짜리 세 종류입니다. 음높이·속도를 낮추고 저음 잡음과 고음을 필터링한 뒤 페이드와 음량 제한을 적용했습니다. 수동 조타와 자동항해 모두 실제 선회 상태에 반응하며 속도가 높을수록 조금 더 크게 들립니다. 최소 1.7~2.3초의 재생 간격과 이전 소리 종료 여부를 모두 확인해 겹침을 막습니다. 직선으로 돌아오면 짧게 페이드아웃하고 정지·입항·음소거·화면 이탈 시에는 중단합니다. 기존 합성 삐걱임 파일은 복구용으로 보존하지만 게임에서는 로딩하지 않습니다.

시작·이어하기를 누른 뒤 바다에 나가면 선체 옆으로 흐르는 물살과 돛을 스치는 바람 소리가 재생됩니다. 해변처럼 크게 밀려왔다 빠지는 파도 대신, 이동할 때 이어지는 잔물살에 드문 목재 삐걱임과 짧은 돛 천의 펄럭임을 작게 섞습니다. 정지하면 물살을 크게 낮추고 선박 소리는 끕니다. 항해 화면과 해도는 같은 소리를 공유하며, 직접 입항하면 짧은 종소리가 나고 바다 소리는 잦아듭니다. 배경음악은 없으며 물살·바람·돛·갈매기는 기존 합성음을 유지합니다.

v38의 입항 종은 제공받은 Pixabay Opening Bell의 세 타격을 편집한 `arrival-bell-recorded.wav`입니다. 타격 간격을 0.18초로 좁히고 음높이·재생속도를 0.94배로 살짝 낮췄습니다. 저음 잡음과 날카로운 고음을 정리하고 마지막 타격에만 약한 잔향을 추가한 2.4초짜리 파일입니다. 원본 MP3와 기존 합성 `arrival-bell.wav`는 덮어쓰지 않습니다. 빠르게 다시 입항하거나 출항하면 이전 종소리는 끊어 중첩을 막습니다.

물살 파일에는 기본 게인 .2와 필터를 미리 적용했고, 물살·바람·선박 소리는 현재 속도에 맞춰 부드럽게 변합니다. 바다에서는 멀리 들리는 갈매기 파일을 간헐적으로 재생합니다. 파일 로딩 후 첫 울음은 약 10~16초 뒤, 이후 약 22~40초 간격이며 항구 안·음소거·백그라운드에서는 울지 않습니다.

입장 화면과 게임 상단의 '소리 켜짐/꺼짐' 버튼으로 전체 음소거를 바꿉니다. 설정은 게임 기록과 별도로 이 브라우저에 저장됩니다. 입장 화면으로 돌아가거나 탭을 숨기면 오디오 처리를 멈춥니다. 모바일 브라우저에서 '소리 대기'가 보이면 화면을 한 번 터치하세요. Web Audio 미지원 환경에서는 소리 없이 게임을 계속할 수 있습니다.

합성 효과음은 `build-audio.cjs`, 외부 녹음 편집본은 `build-recorded-creaks.cjs`와 `build-recorded-bell.cjs`로 미리 만듭니다. 외부 녹음의 출처·이용 조건·편집 내역은 [녹음 크레딧](assets/audio/RECORDING-CREDITS.md)에 기록했습니다. 원본 MP3는 저장소에 포함하지 않습니다. 게임의 Web Audio는 파일 디코딩·믹싱·재생만 담당합니다. 시작·이어하기 후 설정된 9개를 한 번 불러오며 로딩 실패한 효과음은 생략하고 게임은 계속됩니다. 기본 음량은 낮게 설정되어 있고 기기의 미디어 음량으로 조절합니다.

## 경제와 모험

항구별 기본 시세와 기간 한정 수요에 따라 교역하고 선박을 교체합니다. 경제 목표는 항구 8곳 방문, 선박 1회 업그레이드, 금화 5,000 G입니다. 리스본에서 밀을 10자루 구매한 뒤 남쪽 곶을 돌아 동쪽 항구를 찾아 판매해 보세요.

탐험 5곳의 단서를 모아 마지막 서고를 조사합니다. 의뢰 5건은 출발 항구에서 수락하고 직접 물품을 준비해 도착 항구의 의뢰 탭에서 납품합니다. 일반 판매로는 의뢰가 완료되지 않습니다. 시간제한은 없으며 보상은 1회만 받습니다. 모험 목표는 발견 5곳과 의뢰 3건입니다. 추가된 바르셀로나·마르세유·라구사는 현재 교역 거점이며 개별 탐험·의뢰는 없습니다.

## 지도와 역사적 범위

항구 배경은 모든 항구에서 공통으로 사용하는 창작 지중해 풍경이며 특정 도시의 실제 모습을 복원한 그림은 아닙니다. 내장 이미지 생성 도구로 제작한 배경과 생성 프롬프트는 [배경 제작 기록](assets/README.md)에 설명되어 있습니다. 모바일용 WebP 파일은 약 421 KiB이며 시설 버튼과 글자는 이미지가 아닌 HTML로 구현되어 있습니다.

실제 항구: 리스본, 카디스, 제노바, 알렉산드리아, 베네치아, 바르셀로나, 마르세유, 라구사(현재 두브로브니크). 이름과 소속은 1550년경을 배경으로 합니다. 당시 국경선이나 정확한 도시 지형을 복원한 지도는 아닙니다.

해안선은 Natural Earth 1:50m 현대 육지 폴리곤을 메르카토르 좌표로 투영한 것입니다. 당시 매립지·하천·석호의 변화는 복원하지 않았으며, 작은 만과 섬은 데이터 해상도에 따라 생략될 수 있습니다. 화면의 육지 폴리곤과 충돌 판정은 동일한 데이터를 사용합니다. 실제 도시 위치와 입항용 외해 정박점은 구분되며, 강·석호 안쪽의 세밀한 입항은 생략했습니다. 교역 가격, 의뢰, 발견 이야기, 항해 속도와 비용은 역사적 실측이 아닌 게임 규칙입니다.

지형 데이터를 수정·재생성하려면 원본 파일을 유지한 상태에서 다음을 실행합니다.

```powershell
node build-geography.cjs
```

## 저장 호환성

속도와 방향 정보가 없는 기존 저장도 그대로 읽습니다. 위치·금화·화물·항로는 유지하며 재접속 시 속도는 0에서 다시 출발합니다.

v0.1/v0.2/v0.3의 금화·선박·화물·의뢰·탐험을 유지합니다. v0.3 저장은 정박 상태면 항구 화면으로, 해상이면 항해도로 이어집니다. 기존 가상 항구의 방문 기록은 루메→리스본, 세드라→카디스, 아주르→제노바, 사프라→알렉산드리아, 벨항→베네치아로 대응시킵니다. 새 게임은 리스본만 공개되어 있습니다. 기존에 달성한 경제 목표는 유지됩니다.

브라우저 localStorage에 저장하므로 사이트 데이터 삭제, 다른 기기·주소·브라우저에서는 이어지지 않습니다. 멀티플레이·클라우드 저장·결제·광고는 포함하지 않습니다.

같은 모드에서는 한 탭만 플레이·저장합니다. 다른 탭에서 시작·이어하기를 누르면 기존 탭이 항해를 정지하고 마지막 기록을 저장한 뒤 입장 화면으로 돌아갑니다. 새 탭은 저장 권한을 받은 뒤 최신 기록을 다시 읽습니다. 입장 화면만 열어 둔 탭이나 권한을 넘긴 탭의 새로고침·닫기는 기록을 덮어쓰지 않습니다. 새 항해 초기화에도 같은 보호를 적용하며 일반·테스트 모드의 권한과 저장은 별개입니다.

이 보호는 HTTPS 또는 localhost의 Web Locks 지원 브라우저에서 동작합니다. 지원하지 않거나 저장 권한을 확보하지 못하면 입장 화면에 안내를 표시합니다. 기존 탭이 브라우저에 의해 일시 중단되어 응답하지 않으면 해당 탭을 닫아 주세요. v30 이전 탭은 이 보호가 없으므로 업데이트 후에는 기존 게임 탭을 모두 닫고 새로 접속하세요.
