# 교체 가능한 효과음

현재 파일은 기존 합성음의 로직으로 미리 만든 WAV입니다. 실제 현장 녹음이 아니며, 게임 실행 중에는 합성하지 않고 이 파일을 재생합니다. 외부 영상이나 사용자 제공 MP3의 녹음은 포함하지 않았습니다. 생성 코드와 함께 프로젝트 MIT 라이선스로 제공합니다.

| 파일 | 용도 | 재생 방식 |
| --- | --- | --- |
| `water.wav` | 선체 옆 물살 | 10초 루프, 속도에 따라 음량 변화 |
| `wind.wav` | 돛을 스치는 바람 | 12초 루프 |
| `sails.wav` | 돛 펄럭임 | 13초 루프, 여러 펄럭임 사이 여백 포함 |
| `hull.wav` | 평상시 선체 삐걱임 | 17초 루프, 여러 소리 사이 여백 포함 |
| `turn-1.wav`, `turn-2.wav`, `turn-3.wav` | 방향 전환 삐걱임 | 선회 중 변형 하나를 선택해 1회 재생 |
| `gull.wav` | 갈매기 | 바다에서 간헐적으로 1회 재생 |
| `arrival-bell.wav` | 입항 종 | 땡땡땡 전체를 담은 파일, 입항 시 1회 재생 |

## 교체 방법

1. 같은 이름의 WAV 파일로 교체하면 재생 코드를 바꿀 필요가 없습니다. WAV는 PCM 16-bit를 권장하며 샘플레이트와 길이는 고정할 필요가 없습니다.
2. MP3 등 다른 형식이나 파일명을 쓰려면 프로젝트 루트 `audio-config.js`의 해당 `file`을 수정합니다. 로컬 서버와 배포는 이 폴더의 WAV, MP3, OGG, M4A를 지원하며 실제 디코딩 지원은 브라우저에 따릅니다. 파일명은 영문·숫자·하이픈·밑줄을 사용하세요.
3. 파일별 음량은 같은 설정의 `gain`, 전체 음량은 `master`에서 조절합니다. 지나치게 큰 새 녹음은 먼저 음량을 낮춰 확인하세요. 물살·바람 파일에는 현재 기본 음량과 필터가 이미 적용되어 있습니다.
4. `audio-config.js`의 `version`을 올리고 `index.html`의 `audio-config.js?v=...`도 올려 캐시를 갱신합니다. 변경 파일을 배포하면 공개 사이트에도 반영됩니다.
5. 반복 파일은 끝과 시작이 자연스럽게 이어지도록 편집합니다. 종 파일은 빠른 세 번의 타격과 마지막 잔향을 모두 포함해야 합니다. 단일 종 타격을 세 번 재생하는 방식이 아닙니다.

새 파일의 이용 조건은 별도로 확인하고 출처·라이선스를 기록하세요. 기존 합성 파일의 MIT 조건이 교체한 외부 녹음에 자동으로 적용되지는 않습니다.

## 개발용 재생성

`node build-audio.cjs --force`는 기존 합성 효과음 9개를 다시 만듭니다. **교체해 둔 녹음도 덮어쓰므로** 원래 합성음을 복구하려는 경우에만 실행하세요. 게임 실행이나 배포에서는 이 명령을 실행하지 않습니다.

현재 파일은 mono 22,050 Hz / 16-bit PCM WAV이고 전체 크기는 약 2.59 MiB입니다. 시작·이어하기 등 사용자 조작 후 한 번만 불러오며, 입장 화면에만 머물면 다운로드하지 않습니다. 불러오지 못한 효과음은 생략하고 게임은 계속됩니다.
