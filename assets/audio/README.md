# 교체 가능한 효과음

게임에서는 WAV 파일 9개를 재생합니다. v38에서는 선체·선회음·입항 종소리 5개가 사용자가 제공한 Pixabay 음원의 편집본이며, 나머지 4개는 기존 합성음입니다. 게임 실행 중에는 합성하지 않습니다. 녹음의 출처·이용 조건·편집 내역은 [녹음 크레딧](RECORDING-CREDITS.md)에 기록했습니다. 외부 녹음에는 프로젝트의 MIT 라이선스가 적용되지 않습니다.

| 파일 | 용도 | 재생 방식 |
| --- | --- | --- |
| `water.wav` | 선체 옆 물살 | 10초 루프, 속도에 따라 음량 변화 |
| `wind.wav` | 돛을 스치는 바람 | 12초 루프 |
| `sails.wav` | 돛 펄럭임 | 13초 루프, 여러 펄럭임 사이 여백 포함 |
| `hull-recorded.wav` | 평상시 선체 삐걱임 | 18초 루프, 세 구간 사이 여백 포함 |
| `turn-recorded-1.wav`, `turn-recorded-2.wav`, `turn-recorded-3.wav` | 방향 전환 삐걱임 | 2.9 / 2.8 / 2.3초, 선회 중 하나를 선택해 재생 |
| `gull.wav` | 갈매기 | 바다에서 간헐적으로 1회 재생 |
| `arrival-bell-recorded.wav` | 입항 종 | 원본의 세 타격을 0.18초 간격으로 편집, 마지막에 약한 잔향; 2.4초 파일을 입항 시 1회 재생 |

## 교체 방법

현재 모든 소리는 `audio-config.js`의 `sfx.sounds`에 속한 효과음(SFX)입니다. `music.tracks`는 나중에 배경음악(BGM)을 등록할 별도 빈 목록이며 효과음 플레이어가 읽거나 다운로드하지 않습니다. 음악 재생 기능은 아직 없습니다. `sfx.gain`은 효과음 공통 음량, `music.gain`은 향후 음악용 설정입니다. 음소거 저장 키 `windward-audio-enabled`는 기존 설정 호환을 위해 유지하며 현재 효과음에만 사용합니다.

1. 같은 이름의 WAV 파일로 교체하면 재생 코드를 바꿀 필요가 없습니다. WAV는 PCM 16-bit를 권장하며 샘플레이트와 길이는 고정할 필요가 없습니다.
2. MP3 등 다른 형식이나 파일명을 쓰려면 프로젝트 루트 `audio-config.js`의 `sfx.sounds` 안에서 해당 `file`을 수정합니다. 로컬 서버와 배포는 이 폴더의 WAV, MP3, OGG, M4A를 지원하며 실제 디코딩 지원은 브라우저에 따릅니다. 파일명은 영문·숫자·하이픈·밑줄을 사용하세요.
3. 파일별 음량은 같은 설정의 `gain`, 전체 음량은 `master`에서 조절합니다. 지나치게 큰 새 녹음은 먼저 음량을 낮춰 확인하세요. 물살·바람 파일에는 현재 기본 음량과 필터가 이미 적용되어 있습니다.
4. `audio-config.js`의 `version`을 올리고 `index.html`의 `audio-config.js?v=...`도 올려 캐시를 갱신합니다. 변경 파일을 배포하면 공개 사이트에도 반영됩니다.
5. 반복 파일은 끝과 시작이 자연스럽게 이어지도록 편집합니다. 종 파일은 빠른 세 번의 타격과 마지막 잔향을 모두 포함해야 합니다. 단일 종 타격을 세 번 재생하는 방식이 아닙니다.

새 파일의 이용 조건은 별도로 확인하고 출처·라이선스를 기록하세요. 기존 합성 파일의 MIT 조건이 교체한 외부 녹음에 자동으로 적용되지는 않습니다.

## 개발용 재생성

`node build-audio.cjs --force`는 기존 합성 효과음 9개를 다시 만듭니다. **교체해 둔 녹음도 덮어쓰므로** 원래 합성음을 복구하려는 경우에만 실행하세요. 게임 실행이나 배포에서는 이 명령을 실행하지 않습니다.

기존 `hull.wav`, `turn-1.wav`~`turn-3.wav`, `arrival-bell.wav`는 복구용으로 보존하며 게임에서는 로딩하지 않습니다. 편집 녹음은 mono 32,000 Hz / 16-bit PCM WAV, 나머지는 mono 22,050 Hz / 16-bit PCM WAV입니다. 시작·이어하기 등 사용자 조작 후 설정된 9개만 불러오며, 입장 화면에만 머물면 다운로드하지 않습니다. 불러오지 못한 효과음은 생략하고 게임은 계속됩니다.

새 입항 종은 `node build-recorded-bell.cjs --source=C:/path/to/u_7xr5ffk4oq-opening-bell-421471.mp3 --force`로 재생성합니다. 원본 MP3와 기존 합성 종은 변경하지 않습니다.
